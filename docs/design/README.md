# Lo-Fi & Bossa: design handoff

Mac, iPad, iPhone and iPhone Duo. Same features on every device; the layout adapts.

- HANDOFF.md       start here: how the app adapts, iPad, iPhone, iPhone Duo, the in-app generator, open questions
- HANDOFF-mac.md   the Mac handoff, still the reference for shared behaviour, states and copy
- tokens.json      design tokens (Mac, touch and phone sizes, devices)
- icon/            macOS icon, iOS any / dark / tinted, layers for Icon Composer
- artboards/       artboard sources and lfb.css from the Design canvas (read for measurements)
- starter/         multiplatform SwiftUI starter (not compiled): open starter/LoFiBossa/Assets.xcassets in Xcode
